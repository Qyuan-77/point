# 创建桌面快捷方式.bat

## 1. 用途

双击一次，就把本目录里的 `.lnk`（`目标颜色自动点击器.lnk`）复制到当前用户的桌面，省得手动拖图标。复制的是快捷方式本身，不复制程序。

## 2. 变量/字段清单

| 名字 | 含义 | 取值 |
|---|---|---|
| `%~dp0` | 本脚本所在目录（含尾反斜杠） | `D:\seeg\point\` |
| `LNK` | 本目录中 `*.lnk` 的文件名（`%%~nxF`，只取名字不含路径） | `目标颜色自动点击器.lnk` |
| `DESK` | 桌面目录 | 注册表解析值，实测 `C:\Users\lenovo\Desktop` |
| 注册表项 | 桌面路径来源（支持 OneDrive 重定向） | `HKCU\Software\Microsoft\Windows\CurrentVersion\Explorer\User Shell Folders` 的 `Desktop` |
| 回退 | 注册表读不到时 | `%USERPROFILE%\Desktop` |
| 标签 | `:no_lnk` 本目录没有 .lnk；`:fail` 复制失败 | — |

`call set "DESK=%DESK%"` 用来把注册表值里的 `%USERPROFILE%` 之类变量再展开一次（`for /f` 拿到的原文不会自动展开）。

## 3. 输入/输出

- 输入：无命令行参数。
- 读：注册表 Desktop 项；本目录的 `*.lnk`。
- 写：`%DESK%\<LNK>`（`copy /y`，会**静默覆盖**桌面同名文件）。
- 输出：成功打印创建的完整路径与「以后双击桌面图标即可、不会弹控制台」；失败打印原因（本目录无 .lnk / 复制失败并给出目标目录与手动复制建议），都 `pause` 停住。
- 退出码：成功 `0`，失败 `1`。

## 4. 【待确认】

- `copy /y` **覆盖**桌面同名文件：桌面若已有同名图标会被替换，无备份。
- 目录里若有多个 `.lnk`，`for %%F in (*.lnk)` 会不断覆盖 `LNK`，最终只复制**最后一个**（当前项目只有一个 .lnk）。
- 同样遵守 `.bat` 的 **ASCII + CRLF** 约定（原因见 `run.bat.md` 第 4 节）。
- 已实测：桌面解析与复制逻辑在临时目录上跑通（`.lnk` 成功复制到目标目录）；在用户真实桌面上的复制需要提权，未实际执行。
