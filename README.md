# 目标颜色自动点击器

针对“未点击 = 白色/亮色目标，点击后 = 红色圆点”场景的 Windows 桌面工具：
截取指定区域 → 灰度阈值分割 → 找目标 → 点击 → 检测红色反馈 → 排除已完成 → 循环直到完成。

## 环境

已在本机创建 conda 环境 `point_clicker`（Python 3.11，位于 E:\anconda\envs\point_clicker），依赖已装好。

运行方式（二选一）：

- 双击 `run.bat`；
- 或命令行：

```bash
conda activate point_clicker
cd /d D:\seeg\point
python main.py
```

如需在其他机器重建环境：

```bash
conda create -n point_clicker python=3.11 -y
conda activate point_clicker
pip install -r requirements.txt
```

## 使用流程

1. 设置检测区域：直接填 X / Y / 宽 / 高，或点“框选区域”在屏幕上拖出矩形（自动换算为物理像素）。
2. 点“自动校准”：程序分析当前区域，自动填入灰度阈值、最小面积、去重半径、红色验证等参数，并自动预览。
3. 必要时手动微调灰度阈值 bar（0~255，默认 180）：
   - 识别不到目标 → 降低阈值；
   - 背景也被选入 → 提高阈值；
   - 目标偏暗 → 勾选“检测暗色目标”。
4. 点“预览（只识别不点击）”，确认绿色框 + 红色十字覆盖所有待点击位置，且已完成的红点没有被框选。
5. 点“开始”。程序循环截图、逐个点击并等待变红后再处理下一个；全部完成后自动停止（可取消勾选）。
6. 停止方式：
   - 全局热键 **F8**（即使窗口不在前台也有效）；
   - 点界面“停止”按钮；
   - 紧急停止：把鼠标快速移到屏幕左上角（PyAutoGUI fail-safe）。

## 自动校准说明

“自动校准”基于当前检测区域做一次分析：

- OTSU 计算灰度阈值，并结合红点周围的目标亮度校正；
- 统计红色圆点的半径、面积、最近邻间距；
- 统计红点所在白色亮块的面积；
- 自动填入：灰度阈值、最小目标面积、去重半径、成功所需红像素、红区排除占比、验证半径、距离变换中心、点阵间距（由红点间距推断）。

若区域内没有红色圆点，红色验证相关参数保持默认，仅自动设置灰度阈值与最小面积，请用“预览”确认。

## 参数说明

| 参数 | 默认 | 说明 |
|---|---|---|
| 灰度阈值 | 180（校准后自动） | 大于该灰度视为目标；勾选 OTSU 后自动计算 |
| 最小目标面积 | 50（校准后自动） | 过滤噪声点 |
| 去重半径 | 15 px（校准后自动） | 与已成功点击点距离小于该值则跳过 |
| 点击顺序 | 从上到下、从左到右 | y_x（默认）/ x_y（从左到右、从上到下）/ corner（距左上角由近到远） |
| 多点模式 | 开 | 勾选后白色区域内按等距行列生成多个点击点（默认） |
| 点阵间距 | 20 px（校准后自动） | 区域内横竖等距间距；自动校准按已点击红点间距推断 |
| 单帧最多点数 | 800 | 一帧最多生成的点数，防止点阵过密时溢出 |
| 点击间隔 | 0.15 s | 相邻点击最小间隔 |
| 验证等待 | 0.25 s | 点击后等待变红的时间 |
| 最大重试次数 | 3 | 点击后无红色反馈时的重试次数 |
| 成功所需红像素 | 12（校准后自动） | 点击点周围红像素数 ≥ 该值判定成功 |
| 红区排除占比 | 15%（校准后自动） | 轮廓框内红色占比超过该值视为已完成 |
| 距离变换中心 | 开 | 取目标内部离边缘最远的点，避免点到边缘 |

## 目录结构

| 文件 | 作用 |
|---|---|
| main.py | GUI 入口（PyQt6），含自动校准与 F8 全局热键 |
| worker.py | 后台点击线程：循环截图/点击/红色验证 |
| detector.py | 灰度分割 + 连通域 + 红色排除 + 自动校准分析 |
| capture.py | mss 高速截图与 DPI 感知设置 |
| config.py | 参数配置（默认值） |
| run.bat | 一键启动脚本 |
| requirements.txt | 依赖清单 |

## 实现要点

- 坐标统一为物理像素：程序启动时已设置 DPI 感知，mss 截图与 pyautogui 点击使用同一坐标系，避免高 DPI 下点偏。
- 红色判定采用 HSV 双区间（H 0~10 与 170~180，S/V≥70），对深红、亮红都有效。
- 每帧截图会生成该帧识别出的全部待点击点并带编号显示在预览中；程序按顺序点完当前帧全部目标后，重新截图进入下一步；全部完成后自动停止。
- 红色完成判定优先检查“点击中心是否变红”，避免红色标记扩散时误把相邻目标排除。
- 点击后先等待 `验证等待` 秒，再统计点击点周围红像素；不足则重试，直到超过 `成功所需红像素`。
- 失败的点不会永久跳过：下一轮扫描仍会尝试，直到用户停止或该点变红。若某个点持续失败，请检查点击位置是否被遮挡、目标窗口是否在前台、验证参数是否过严。
- 程序本身不保存任何截图，仅实时抓帧分析。
- “预览”为单帧静态识别；真实点击效果还取决于目标窗口在前台、点击位置是否被其他窗口遮挡。

## 常见问题

- 预览什么都检测不到：降低灰度阈值，或勾选“检测暗色目标”；确认区域在屏幕范围内。
- 背景也被选中：提高阈值，或增大“最小目标面积”。
- 点击后一直报失败：检查红色判定参数（成功所需红像素、验证等待）；若红点较小可降低红像素阈值。
- F8 不生效：确认程序启动日志显示“已启用全局热键”；若被其他软件占用，可修改 main.py 中的 `"<f8>"` 为其他按键。
- 多显示器：区域选择以主屏缩放为准，多显示器混合 DPI 时请手动核对坐标。
