# 目标颜色自动点击器

针对“未点击 = 白色/亮色目标，点击后 = 红色圆点”场景的 Windows 桌面工具：
截取指定区域 → 灰度阈值分割 → 找目标 → 点击 → 检测红色反馈 → 排除已完成 → 循环直到完成。

## 环境

已在本机创建 conda 环境 `point_clicker`（Python 3.11，位于 E:\anconda\envs\point_clicker），依赖已装好。

运行方式（三选一）：

- **双击 `目标颜色自动点击器.lnk`**（推荐）：用 `pythonw.exe` 静默启动，不弹控制台窗口；
- 双击 `run.bat`：保留控制台窗口，启动失败时能看到报错（排错用这个）；
- 命令行（用绝对路径调用解释器，不要用 `conda activate`）：

```bash
E:\anconda\envs\point_clicker\python.exe D:\seeg\point\main.py
```

想给桌面也放一个图标：双击一次 `创建桌面快捷方式.bat`，它会把 `目标颜色自动点击器.lnk` 复制到桌面。

如需在其他机器重建环境：

```bash
conda create -n point_clicker python=3.11 -y
pip install -r requirements.txt
```

## 打包成独立 exe（可选）

双击 `打包为exe.bat`：首次会联网安装 PyInstaller，然后产出 `dist\TargetClicker.exe`（单文件、无控制台窗口、目标机器不需要 Python/conda），产出后可自行重命名。

- 想启动更快：把脚本里的 `--onefile` 改成 `--onedir`（产出整个文件夹，需一起复制）；
- 单文件版首次运行要解压到临时目录，启动约慢 3~10 秒；
- 打包脚本只影响 `dist\` 与 `build\`，不会改动源码。

## 使用流程

1. 设置检测区域：直接填 X / Y / 宽 / 高，或点“框选区域”在屏幕上拖出矩形（自动换算为物理像素）。
2. 点“自动校准”：程序分析当前区域，自动填入灰度阈值、最小面积、去重半径、红色验证等参数，并自动预览。
3. 必要时手动微调灰度阈值 bar（0~255，默认 180）：
   - 识别不到目标 → 降低阈值；
   - 背景也被选入 → 提高阈值；
   - 目标偏暗 → 勾选“检测暗色目标”。
4. 点“预览（只识别不点击）”，确认绿色框 + 红色十字覆盖所有待点击位置，且已完成的红点没有被框选。
5. 点“开始”。程序循环截图、逐个点击并等待变红后再处理下一个；全部完成后自动停止（可取消勾选）。
6. 运行中随时可以 **F11 暂停 / 继续**，或点界面“暂停”按钮。
7. 停止方式：
   - 全局热键 **F8**（即使窗口不在前台也有效）；
   - 点界面“停止”按钮；
   - 紧急停止：把鼠标快速移到屏幕左上角（PyAutoGUI fail-safe）。

## 快捷键（全局，窗口不在前台也有效）

| 按键 | 作用 |
|---|---|
| F9 | 预览（只识别不点击） |
| F10 | 开始 |
| F11 | 暂停 / 继续 |
| F8 | 停止 |

## 自动模式（只截一次图）

勾选「自动模式（只截一次图）」后点“开始”：

1. 只截一次图，识别该帧内的全部目标；
2. 按「点击顺序」逐个点击，每个点都做红色反馈验证与重试；
3. 全部点完后，按一次「翻页方向」指定的按键（向下 = PageDown，向上 = PageUp）；
4. 线程自动结束（等同于点“停止”）。

要点：

- 「翻页方向」只决定按哪个键，与「点击顺序」互不影响；未勾选自动模式时该下拉不可用。
- 该帧 **一个目标都没识别到时不按键**，避免在空页面上盲目翻页；日志会明确说明。需要跳过空白页时，可先确认预览，再手动按键或临时用循环模式。
- 自动模式本身就是“一次即止”，因此「完成后自动停止」在该模式下会自动置灰。
- 需要连续处理多页时，每次按 **F10** 都会重新截一次图，可连续按；或改用循环模式。

## 自动校准说明

“自动校准”基于当前检测区域做一次分析：

- OTSU 计算灰度阈值，并结合红点周围的目标亮度校正；
- 统计红色圆点的半径、面积、最近邻间距；
- 统计红点所在白色亮块的面积；
- 自动填入：灰度阈值、最小目标面积、去重半径、成功所需红像素、红区排除占比、验证半径、距离变换中心、点阵间距（由红点间距推断）。

若区域内没有红色圆点，红色验证相关参数保持默认，仅自动设置灰度阈值与最小面积，请用“预览”确认。

## 参数说明

| 参数 | 默认 | 说明 |
|---|---|---|
| 灰度阈值 | 180（校准后自动） | 大于该灰度视为目标；勾选 OTSU 后自动计算 |
| 最小目标面积 | 50（校准后自动） | 过滤噪声点 |
| 去重半径 | 15 px（校准后自动） | 与已成功点击点距离小于该值则跳过 |
| 点击顺序 | 从上到下、从左到右 | y_x（默认）/ x_y（从左到右、从上到下）/ corner（距左上角由近到远） |
| 多点模式 | 开 | 勾选后白色区域内按等距行列生成多个点击点（默认） |
| 点阵间距 | 20 px（校准后自动） | 区域内横竖等距间距；自动校准按已点击红点间距推断 |
| 单帧最多点数 | 800 | 一帧最多生成的点数，防止点阵过密时溢出 |
| 点击间隔 | 0.15 s | 相邻点击最小间隔 |
| 验证等待 | 0.25 s | 点击后等待变红的时间 |
| 最大重试次数 | 3 | 点击后无红色反馈时的重试次数 |
| 成功所需红像素 | 12（校准后自动） | 点击点周围红像素数 ≥ 该值判定成功 |
| 红区排除占比 | 15%（校准后自动） | 轮廓框内红色占比超过该值视为已完成 |
| 距离变换中心 | 开 | 取目标内部离边缘最远的点，避免点到边缘 |
| 验证半径 | 12（校准后自动） | 高级参数：判断“已变红”时统计点击点周围多大的范围 |
| 自动模式 | 关 | 开：只截一次图，点完该帧全部目标后按一次翻页键并结束 |
| 翻页方向 | 向下（PageDown） | 自动模式结束时按下的键：向下=PageDown，向上=PageUp |

## 实现要点

- 坐标统一为物理像素：程序启动时已设置 DPI 感知，mss 截图与 pyautogui 点击使用同一坐标系，避免高 DPI 下点偏。
- 红色判定采用 HSV 双区间（H 0~10 与 170~180，S/V≥70），对深红、亮红都有效。
- 每帧截图会生成该帧识别出的全部待点击点并带编号显示在预览中；程序按顺序点完当前帧全部目标后，重新截图进入下一步；全部完成后自动停止。
- 两种运行模式共用同一套点击/验证代码：循环模式反复截图；自动模式只截一次图，点完后按一次翻页键并结束。
- 暂停是“就地挂起”：等待间隔与验证环节都会检查暂停标志，暂停不丢进度；停止则立即从安全点返回。
- 红色完成判定优先检查“点击中心是否变红”，避免红色标记扩散时误把相邻目标排除。
- 点击后先等待 `验证等待` 秒，再统计点击点周围红像素；不足则重试，直到超过 `成功所需红像素`。
- 失败的点不会永久跳过：下一轮扫描仍会尝试，直到用户停止或该点变红。若某个点持续失败，请检查点击位置是否被遮挡、目标窗口是否在前台、验证参数是否过严。
- 程序本身不保存任何截图，仅实时抓帧分析。
- “预览”为单帧静态识别；真实点击效果还取决于目标窗口在前台、点击位置是否被其他窗口遮挡。

## 常见问题

- 预览什么都检测不到：降低灰度阈值，或勾选“检测暗色目标”；确认区域在屏幕范围内。
- 背景也被选中：提高阈值，或增大“最小目标面积”。
- 点击后一直报失败：检查红色判定参数（成功所需红像素、验证等待）；若红点较小可降低红像素阈值。
- 热键不生效：确认程序启动日志显示“已启用全局热键”；若被其他软件占用，可修改 main.py 中 `_start_hotkeys()` 里 `<f8>/<f9>/<f10>/<f11>` 的映射。
- 自动模式没按键：该帧没有识别到目标时程序不会按翻页键（日志会写明），请先预览确认识别正常。
- 自动模式按错方向：检查「翻页方向」下拉；它只决定按 PageUp 还是 PageDown。
- 多显示器：区域选择以主屏缩放为准，多显示器混合 DPI 时请手动核对坐标。
- 双击 `run.bat` 报「'xxx' 不是内部或外部命令」或一整片乱码：该 .bat 被存成了 LF 行尾或含非 ASCII 字符，cmd.exe 会解析失败。**本项目的 .bat 必须保持 CRLF 行尾 + 纯 ASCII 内容**；中文说明写在本 README 里，不要写进 .bat（细节见 `code_explain\run.bat.md`）。
- 控制台出现 `SetProcessDpiAwarenessContext() failed: 拒绝访问`：程序自己先设过 DPI 感知，Qt 再设就被拒绝，属正常提示，不影响点击坐标；`run.bat` 已用 `QT_LOGGING_RULES=qt.qpa.window=false` 屏蔽该行。
- 桌面图标没出现：先确认 `创建桌面快捷方式.bat` 与 `目标颜色自动点击器.lnk` 在同一目录，再双击前者；若提示复制失败，手动把 .lnk 拖到桌面即可。
- 打包失败或很慢：先确认能联网（首次要装 PyInstaller），`--onefile` 打包 PyQt6 + OpenCV 通常要几分钟、产物上百 MB，属正常。
